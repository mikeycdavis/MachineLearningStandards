## What

Ten rule-bound detectors under use/mention discipline — comments stripped and strings
blanked for code signals, so prose naming a library never counts as use of it — each asserted
against a fixture that must provoke it and one that must not.

## Why

False positives are the historically shipped bug class in this kind of scanner. Asserting
only the positive direction ships a detector that fires on everything.

## Notes

The design document was written first, with a rejected-detector table: target leakage
inferred from column names, metric appropriateness, calibration verification, cherry-picked
periods. Each would have produced confident output about something it cannot see.
