## What

Twenty-six project states with literal file contents, locked against the disposition the
evaluator reaches on each. Any difference blocks with exit 3 until the baseline is deliberately
updated. Both directions block.

## Why

A state that newly passes is a weakening. A state that newly fails makes existing
adopters non-compliant without their having changed anything, and deserves the same review.

## Notes

Expectations for all twenty-six states were written from the standards before the
checker was first run. Twenty-five matched; the one that did not is recorded in the baseline
rather than overwritten, because the expectation was wrong and the code was right.

Coverage is stated rather than implied: ten rules of forty-five. The other thirty-five have no
observable acceptance predicate, and the gate prints that beside its clean result.
