## What

The catalog baseline check, policy weakening detection, attestations that cannot
override a mechanism, content digests that expire a stale review, and mutation tests that prove
each guard bites.

## Why

A rule forbidding the weakening of rules is worthless if the only thing enforcing it is
intention. Each route closes a specific bypass.

## Notes

The mutation tests matter more than the guards. A test named for an invariant
establishes nothing unless removing the guard makes it fail, so each one does exactly that on a
copy of the source.
