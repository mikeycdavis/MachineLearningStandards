## What

Scope is what the project tracks, asked of git; where git cannot answer, unowned trees
are recognised by structure. `--include-unowned` covers the case where vendored code genuinely
is the product, and the scan envelope carries `scope` stating how the decision was made.

## Why

Across three targets, no finding now cites code the project did not write.

## Notes

The scope reporter had also been calling a real repository "not a git repository" when
git declined under `safe.directory`. It now names git's own reason — the model is exact when git
answers and an approximation when it does not, and it says which.
